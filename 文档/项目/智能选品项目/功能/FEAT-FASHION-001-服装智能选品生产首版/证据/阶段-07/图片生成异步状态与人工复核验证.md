## 4. 执行中发现与修正

1. 首轮图片浏览器用例直接对 Element Plus 隐藏的原生 checkbox 执行 `check()`，等待超时；改为点击可见标签后，图片定向用例和全量 5/5 均通过。业务代码未通过放宽复核规则来迁就测试。
2. 自审发现初版幂等只比较组合、类型、来源和输入 hash；已补为同时比较候选数量与净化参数。上传还比较内容 SHA-256，相同 `requestKey` 复用为不同意图时返回 409。
3. 自审发现人工复核请求携带的 `rowVersion` 未在服务入口比较；已在写复核历史前校验，并继续由仓储层条件更新形成第二道并发保护。
4. 自审发现月度预算若只读合计可能被并发任务超额预留；已在创建 Provider 任务的短事务内锁定预算配置行，再重新检查幂等和已承诺费用。
5. 自审发现 UNKNOWN 若没有 Provider task ID，可能再次提交；已改为仅初始 queued 可 submit，UNKNOWN 始终使用原 `requestKey` query。取消请求可抢占租约，旧 Worker 的晚到结果因 rowVersion fencing 被拒绝。
6. 观测初版只有任务状态计数；最终增加终态耗时和结算费用直方图，采用、复核和取消保持事件计数，所有标签使用固定白名单。
