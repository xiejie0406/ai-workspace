# 智能选品项目

> 项目全称：服装智能选品项目（历史名称：服装智能选品与报价项目）；ID：PROJ-FASHION-003  
> 文档类型：项目控制入口；文档状态：Draft  
> owner：用户维护产品方向；Codex 维护实际工程与文档事实  
> 创建日期：2026-09-10；更新日期：2026-10-01

本项目为商品运营和销售提供商品资料内价格/图片维护、基础字段导入、仓库管理与库存、主SKU选品、阿里云模特试衣、PPT提案和文件交付。代码沿用 `ruoyi-backend/ruoyi-fashion`、`frontend/admin-web` 与唯一 `python/fashion-ai-runtime`；浏览器只访问 Java，Java/MySQL 持有业务事实，Python 提供受控建议。

2026-10-01 用户已认可五章结构并要求开始重写。现在项目只有[智能选品系统设计方案](架构/技术架构设计.md)这一份现行系统设计；原架构、Python、数据库、Feature 技术及选品交互设计已归并。结构与合并授权不代表全部设计内容、实现或业务验收已被接受。最新1.2修订采用Fashion顶部导航，将价格和图片归入商品资料，补基础字段模板、完整列表字段与编号业务流程，并在唯一设计第4章规划主控＋三个执行智能体编码；2/3/4组复用和正式报价退出沿用。[可交互设计稿](功能/FEAT-FASHION-001-服装智能选品生产首版/商机套装选品线框图.html)为配套资产。用户随后明确“开始做”，按1.2完成两批源码改造、交叉审查与最终技术检查；数据库增量、真实Provider及上线尚未执行。业务验收仍暂停，实际进展、证据和未完成项从下列唯一记录读取。
