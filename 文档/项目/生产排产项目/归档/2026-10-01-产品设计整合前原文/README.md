## 恢复方法

1. 先保存整合后及后续新增修改，比较当前文件与新正文交付版本；不得用恢复动作覆盖后来工作。
2. 根据`原文清单.json`核验精确原文哈希。按清单的`source`复制对应`raw`文件回工作区原路径；复制的内容本身不含额外历史说明。不要用“可读历史”作为精确恢复源。
3. 同时恢复需要回退的项目入口、Feature、任务和图稿浏览页；原型入口如已新增内容先手工合并。新正文先保留为快照，是否退出现行入口由恢复决定说明。
4. 检查旧入口、相对链接和图稿可查看性。恢复不回滚代码、数据库、运行进程、生产事实或原验收结果。
