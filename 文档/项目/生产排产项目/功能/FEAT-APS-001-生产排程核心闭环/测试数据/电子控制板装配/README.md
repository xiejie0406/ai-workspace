## 第一条能够手算的业务链

仅选择订单`TEST-PCBA-202610-001`，20件，无其他任务竞争、物料准备好、全部合格、质量释放和转运不额外耗时，09:00开始：

| 工序 | 计算 | 无等待区间 |
|---|---|---|
| 插件/补焊 | 600秒准备 + 20×60秒 = 30分钟 | 09:00–09:30 |
| 烧录 | 300秒准备 + 20×30秒 = 15分钟 | 09:30–09:45 |
| 功能测试 | 300秒准备 + 20×90秒 = 35分钟 | 09:45–10:20 |
| 外观检验 | 20×30秒 = 10分钟 | 10:20–10:30 |
| 包装 | 20×30秒 = 10分钟 | 10:30–10:40 |

总时长100分钟，最早10:40完成。它是本设定条件下的可行手算基线及时间下界，不保证求解器一定选择同一人员或相同设备，也不代表真实生产节拍。

“手算基线”从“工序参数”取值；可改B5数量与B12起始时间。工序参数中的黄色工时可编辑。数量为10件时为60分钟；把功能测试单件时间改为120秒、保持20件时为110分钟。空数量或零数量显示“缺数量”，不会算成正常零件订单。

之后逐个执行“测试场景”中的共享冲突、午休、缺料、停机、技能到期、质量损失和不可达交期。异常预期是事先定义的业务判断，没有被标记为本系统已通过。
