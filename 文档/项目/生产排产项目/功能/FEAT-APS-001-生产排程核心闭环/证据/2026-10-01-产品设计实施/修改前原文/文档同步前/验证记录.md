## 1. 验证范围和结论边界

本记录证明 IMP-01～IMP-09 的既有技术闭环，并继续记录 IMP-10 的增量事实。2026-09-13 已完成日报、人力产能、订单交期/ETA、CSV/打印、权限审计和机器契约纵切片；固定 1k/5k/20k 本机工程基准在确定性完整 hint 优化后，对独立单阶段合成形态形成有限 Go；单 Worker 遗留状态回收、优雅停机、发布切换故障回滚/重试和数据库逻辑恢复已有本地证据。PRD AC-01～24 与 21 项 P0 APS-AC 的技术回归矩阵均已通过。用户明确 Windows 为目标后，又在固定 JDK 17 下实际完成 OR-Tools JNI、前后端制品、Worker 和 API 启动复验。真实业务库迁移、真实账号/设备联调、复杂业务容量、UAT 或上线就绪仍没有完成证据，因此 IMP-10 保持 `InProgress`。

当前结论为：

- Java 17 后端骨架、依赖方向、API 双开关、Worker 三开关、独立非 Web 入口和 Windows OR-Tools JNI smoke 通过。
- OpenAPI 3.1、JSON Schema 2020-12、16 个正反例、JCS 基准与黄金摘要通过统一契约门禁；Schema 不能代替后续跨对象业务校验。
- 前端严格类型检查、10 个文件 27 项单测及系统 Chrome 17 项 APS 浏览器用例通过；最新 500 资源 / 5,000 分段首屏为 16.0850 秒，继续只判定适配路线“受限 Go”，不判定尚无批准阈值的性能通过。
- V001 与评审 DDL 正文一致且保持不可变；生产向前迁移 V002～V005 分别覆盖受控可中断、结构调整幂等、数量冲正与活动 run carry 身份，V006 为 M26 增加来源计划分配身份和复合外键。独立临时 MySQL 8.0.46 上 migrate/validate/重复 migrate、测试 V007 前进升级、当前 29 表/66 外键、约束反例、UTC 毫秒、事务回滚、乐观锁、权限 SQL 幂等及逻辑备份恢复均通过；V001 静态基线仍为 64 外键。
- APS 数据源、Flyway、API 和 Worker 均默认关闭；缺少独立 APS URL 时失败关闭，不回退到 RuoYi 主库；健康端点匿名可用，能力端点的真实 Spring Security HTTP 验证为无权限 403。
- M01～M05 的 CRUD/启停、单表多技能、绝对时间窗、事务导入、净日历、候选筛选、就绪问题、车间范围和人员导出权限已实现；隔离 MySQL、单测和 Chrome 页面夹具通过。
- M06～M18 的产品/工序/阶段资源要求、版本化路线 DAG、多产品订单、四类生产批、任务/依赖/物料展开、V1/V2 隔离和显式迁移确认已实现；`SAME_START` 保留且阻断发布/释放。
- M01～M18 可编译为稳定 hash 的 SolverInput；独立校验器不依赖 OR-Tools，能复验资源/日历/阶段/依赖/容量/批次/锁/实际占用/水位，并对非法输入失败关闭。
- 基础 CP-SAT 已实现有限资源、净日历、席位、人机阶段、完成依赖、可信开放占用、未来 carry 和交期目标；M19 请求/状态/取消、单 Worker CAS、M20～M23 原子候选、独立复验和 SSE 状态恢复已有实测证据。
- IMP-07 已实现比例/数量门槛、转移批对齐、连续释放尾批、有限产出/物料预约、待检不释放、受控拆批扣减、人工计划固定共享批、影响闭包、受控可中断 RUN 阶段、可信正式基线冻结、非冻结稳定性目标、O-100，以及作业/分段/资源分配三级时间锁、资源锁和全锁；M24 细粒度锁可由当前正式基线映射到重排输入，IMP-07 标记 `Done`。

- IMP-08 系统内发布已完成技术纵切片：串行化短事务复验事实水位、输入/候选摘要、当前 M24 与独立硬约束，原子废止旧正式版本并切换唯一 current；发布原因进入 M19，未配置外部接收方时只返回 `NOT_APPLICABLE`。用户已接受该发布语义，IMP-08 标记 `Done`。
- IMP-09 已实现 M25/M26 run 生命周期和实际占用、M27 部分/完工报工及更正、M28 产出批和质量处置、M29 不可变数量事件，以及返工/补产血缘、M13～M16 聚合、服务端执行水位、实际放行供应和现场工作台。同一 M26 按物理 `occupancyId` 聚合；开工只打开首阶段，暂停/恢复只处理当前阶段，换资源保留 `sourcePlanAllocationId`，阶段推进原子打开下一阶段且只有末阶段允许完工。活动 run 的当前阶段形成固定事实段，全部后续连续或受控可中断阶段进入同一 `CARRY` 作业，参加资源/日历/顺序/依赖约束并在最终阶段统一释放；未分配余量形成 `SPLIT`。部分共享 run 或历史占用缺少可唯一还原的成员/分配事实时仍失败关闭。
- IMP-10 已实现日冻结基线、跨日计划/实际计量、多技能人员去重、按 `valid_from/valid_to` 生效的技能潜力与峰值、多席位需求、`UNKNOWN` ETA、CSV/打印、权限审计和报表 OpenAPI；隔离 MySQL 已执行真实 Mapper SQL。Java 17 本机固定容量基准中，1k/5k/20k 独立单阶段形态均在 30 秒求解上限内得到经独立校验的可行候选，当前为有限 Go；复杂业务形态与未经验证的生产硬件未据此判定。Actuator、CycloneDX SBOM、依赖 high 门和敏感日志初筛已完成。Windows 目标运行时的 JNI、制品与进程启动已通过；生产级故障/安全演练与 UAT 仍保留真实缺口，IMP-10 为 `InProgress`。
