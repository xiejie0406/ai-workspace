# AI 图片编辑 React 业务库

本工程完整迁入 `参考项目/ai-picture-editor-main/frontend/src` 的业务页面、Konva 画布、图层与选区交互、11 项调色、自然语言计划、营销、投放、批量和导出。前端保留原 React 19 / TypeScript / Konva / TanStack Query / Zustand 栈与原依赖版本，不使用 Vue 重写画布。

平台登录、注册、主菜单、Layout、TagsView、身份与权限、共享 request、通知和最终下载由若依宿主提供。业务内容使用 ShadowRoot 隔离 Tailwind；库内没有自有 JWT、独立导航、BrowserRouter、直连 Python、原生认证 fetch 或 EventSource。

## 使用与检查

在本目录运行 `npm ci --ignore-scripts`、`npm run typecheck`、`npm run build`、`npm test`。库输出 `dist/aipicture-workbench.js`，CSS 已内联到实例 ShadowRoot。`npm run lint` 只检查源码和测试入口；原画布代码仍有 React hooks/ref 提示，不把提示说成已修复。

宿主通过 `mount(container, host)` 挂载，返回 `{ update(host), unmount() }`；同时提供 `update(container, host)` 与 `unmount(container)`。正式接口是 `src/host/HostContract.ts`。`host.identity` 只传用户稳定标识，不能传长期凭据；所有请求交给共享 request。宿主页支持 `create/editor/candidates/marketing/batch/guide/exports`，能力和评测页面由 `frontend/admin-web` 的若依页面提供。

`host.active=false` 会同步退出组件、停止事件、取消请求和清理 Query/Zustand/授权 blob；身份、权限或业务页/会话/任务参数变化同样清理。每个 mount 拥有独立 QueryClient、画布与图层状态、图片解码缓存。编辑器快捷键只监听所属影子根中的业务节点，跳过 input、textarea 与 contenteditable；不会拦截别的业务页或其他编辑器。

所有 API 以 `/aipicture` 开头。adapter 显式转换 AjaxResult / TableDataInfo、`executing/cancelled` 状态、批量 queued 子项、毫秒日期和旧 `image` 素材类型。会话写请求用正式 `row_version` 作为 `expectedVersion`，附带 `schemaVersion=1`、`toolRegistryVersion=2026.10-r2` 与幂等标识。Java 是最终权限和 owner 检查者。区域遮罩由 Java 从正式选区冻结注入，客户端不传服务端资产路径。

素材预览通过鉴权 `/assets/{id}/download` 获取 blob，忽略 DTO 的直接 URL。选区与导出按目标异步协议登记 run、有界轮询，然后读取正式 selection 或 `/exports/{id}/download`。未知外部结果单独显示并阻止计划自动重试；批量未知项另计待核对数量，提示潜在费用并移除该项重试入口。无选区区域工具可手动作用整层，计划展示正式目标、固定选区、参数、输出和模型费用提示。最终文件交给 `host.download`。任务GET的网络/5xx暂错按已有错误分类有界续读同一run，选区正式结果回读也沿用此策略；鉴权/不存在/终态失败不自动重试，失活或换身份中断原等待上下文，不重新POST选择或导出。

画布文字与内联编辑框显式使用同一中文字体栈：Windows 优先 Microsoft YaHei，macOS 为 PingFang SC，Linux 为 WenQuanYi Micro Hei / Noto Sans CJK SC。本机已有 `C:/Windows/Fonts/msyh.ttc`，没有下载或分发字体。宿主可通过 `textFontFamily` 覆盖，若依现有构造从 `VITE_AIPICTURE_TEXT_FONT_FAMILY` 读取；受控自定义 family 必须已在浏览器可用，并与 Worker 的 `AIPICTURE_FONT_PATH` 对应同一字体。字体实际文件、family、指纹、加载及中文探针由“文字渲染”能力报告提供；字体配置与技术检查不替代浏览器中文字形/换行和导出质量验收。

创作提示词随输入写入既有按用户作用域的草稿，保留未提交换行格式；同用户标签失活/重挂载可恢复，正式提交成功或身份退出清除对应草稿，迟到旧用户回复不清新草稿。若依退出保留user.id时，薄宿主从原user.token登录状态映射无身份，触发现有草稿清理；正常同用户token刷新与标签切换保留草稿，不向React传token。换背景、区域替换和11项调色保留待重试参数，只在正式succeeded/partial_success且未有后续用户修改，或用户明确重置后清除；POST接受、版本冲突、读取暂错、Worker失败/取消/未知结果均不提前清空，旧任务回读迟到成功也不清新调色值。

创作1500字与营销文案200字沿唯一工具schema按Unicode码点计数，表情与扩展汉字不算两个字；UI计数及提交前检查均使用原trim后的内容。移除会提前截断合法码点输入的原生UTF-16 maxLength，超限显示原文本和提示、阻止相关生成提交，缩短后可继续；草稿、IME输入、Enter/Shift+Enter以及种子/反向提示/参考图/数量/比例协议保持。

拖动、拖角、内联文字和裁剪沿同一正式工具命令等待结果。失败先回读正式画布与历史，拖动和倍率撤去本地钉住值；原拖动/倍率参数可由用户点击既有反馈中的“重试”，提交版本固定为原正式row_version，若画布已更新则阻止旧参数覆盖并提示重新核对图层。文字与裁剪失败保留原输入/框，正式成功才关闭；等待响应不能重复提交，明确Esc/取消、失活或换身份后迟到回复不重新打开编辑模式。此处补齐原项目同样存在的失败恢复不足，未改变布局、图层字段、字体或缩放坐标协议。

## 原功能对应

原 75 个 `src` 文件逐文件对应与源 SHA256 保存在 `migration-coverage.json`，其中 10 个身份、导航和提示外壳由若依设施替代，65 个业务文件全部保留或适配。`PlaceholderPage` 是源未使用占位，继续保留资料，不宣称已有入口。

| 原页面 | 目标入口与保留功能 |
|---|---|
| LandingPage | `guide` 内部创作指南；示意卡片、需求草稿和创作跳转保留，宣传账号页头移除 |
| AuthPage | 若依既有登录和注册，React 不维护第二套账号 |
| CreatePage | `create`；生成、上传、分组素材、草稿、1–6 候选、五比例、seed、反向提示和最多 3 张参考图 |
| CandidatesPage | `candidates` 隐藏深链；状态、候选墙、采用一张及全部候选带入会话 |
| EditorPage | `editor`；完整 Konva 拖动缩放旋转、裁剪翻转、图层/文字/透明度、上一版本对比、快捷键、撤销重做、选区/笔刷历史、图片墙和 Agent 卡片 |
| MarketingPage | `marketing`；四类营销、1–4 候选、五比例、200 字文案、确定性留白投放、物料选择和 ZIP |
| BatchPage | `batch`；1–20 张、六类串行操作、PNG/JPG、历史任务、进度、逐项结果、部分成功、取消未开始项、失败项重试和成功项 ZIP |
| 新 ExportPage | `exports` 隐藏深链；完整物料清单、manifest ZIP、正式画布 PNG 与可选透明背景 |

批量一次选择多文件时，沿用共享上传 API 按选择顺序逐文件上传；成功项全部加入本页待处理列表，具体失败文件与原因保留，失败不阻断后项。已选与待上传总数最多 20，超限文件不上传；整轮上传完成前不能开始批量或插入历史素材，页面失活后不再处理未开始文件。原项目连续 `mutate(file, { onSuccess })` 只消费末次页面回调，这里按已批准完整批量要求补齐，参考源码未修改。同轮非法文件提示不会被后面的合法文件清除。

22 个工具的业务入口均保留：`generate_image` 在创作，`batch_process` 在批量，`generate_marketing/prepare_delivery_sizes` 在营销，其余 18 个在完整编辑器工具栏、图层/调色面板及自然语言计划。原 `LayerPanel` 11 项调色、文本样式、排序、显隐和变换完整保留；`CanvasStage`、笔刷、选区历史和低分辨率预览算法继续使用原实现。
