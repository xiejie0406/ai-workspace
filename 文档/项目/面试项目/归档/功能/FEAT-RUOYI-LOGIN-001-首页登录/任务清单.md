## 2. 执行包

- 允许修改：本 Feature 目录、`frontend/src`、`frontend/vite.config.ts/js`；必要的跨端代理/兼容包装仅限不创建旧认证状态。
- 允许验证：`npm run build`（frontend）、RuoYi `mvn -DskipTests package` 与启动/HTTP 冒烟、Playwright 流程和 Network 检查。
- 禁止：删除/移动历史文件、数据库写入或迁移、发布、Git 操作、记录密码/Token/Cookie/Secret。
- 停止条件：出现第二套 Token/Session、旧 auth 写入、前端信任 user_id/role/tenant、秘密泄露或后端主体无法从 SecurityContext 获取。
