## 1. 当前主页登录流程图

```mermaid
flowchart TD
  A[访问 frontend 5173] --> B[SessionProvider 调用旧 /api/v1/me]

  D --> E[POST /api/v1/auth/login]
  E --> F[旧 AI Cookie + AIC-XSRF-TOKEN]
  F --> G[业务路由守卫按 tenantId/userId 放行]
```

## 2. 冲突清单

| 现状 | 处理 | 原因 |
|---|---|---|
| `/api/v1/auth/login`、`register`、`logout`、`/me` | 停用 | 不得继续作为认证入口或当前主体来源 |
| `AIC_SESSION`、`AIC-XSRF-TOKEN`、`credentials: include` | 停用 | 不再创建或依赖 AI 自建 Session/Cookie |
| Vite proxy `127.0.0.1:8080` | 改造 | 统一到 RuoYi `127.0.0.1:8081` |
| 主页没有验证码 | 改造 | 登录 DTO 必须包含 `username/password/code/uuid` |
| `tenantId/userId` 由旧 `/me` 返回并进入前端 scope | 改造 | 用户、角色、权限来自 RuoYi `/getInfo`；tenant 只能由后端业务解析 |
| 登录态仅由 `/me` 判断 | 改造 | 路由守卫基于 RuoYi Token + `/getInfo` |
| 注册页提交旧注册接口 | 停用入口 | 保留说明页，不创建第二套账号体系 |
| admin-web RuoYi token 基线 | 保留 | 作为协议和错误语义参考；本轮不复制其第二份状态 |
| mobile/portal-web 旧业务入口 | 兼容期停用候选 | 本轮完成源码扫描并记录；其正式迁移需独立任务 |

## 3. REQ / BR

- REQ-01：登录表单提交 RuoYi `/login`，字段为 `username/password/code/uuid`，密码只存在内存表单状态。
- REQ-02：验证码来自 RuoYi `/captchaImage`，支持刷新和失效后重新获取。
- REQ-03：成功后只保存一个 RuoYi Token；随后读取 `/getInfo` 与 `/getRouters`。
- REQ-04：刷新从该 Token 恢复；Token 缺失、过期或任一受保护接口 401 时清理并跳转 `/auth/login`。
- REQ-05：403 显示无权限，不伪造角色、user_id、tenant 或绕过后端权限。
- REQ-06：退出先调用 RuoYi `/logout`，再清理本地 Token 和内存用户/权限。
- REQ-07：主页源码不再调用旧 AI auth 或 `/me`；注册入口不创建旧账号或会话。

## 4. AC

| AC | 优先级 | Given | When | Then | 覆盖方式 |
|---|---|---|---|---|---|
| AC-01 | P0 | 未登录访问受保护主页 | 打开 `/app` | 跳转 `/auth/login`，Network 无旧 auth 请求 | 浏览器/Network |
| AC-02 | P0 | 登录页已打开 | 获取验证码并提交错误验证码 | 调用 `/captchaImage`、`/login`，显示 RuoYi 错误且可刷新 | 浏览器 |
| AC-03 | P0 | RuoYi 账号有效 | 提交正确四字段 | 仅保存 Token，随后成功读取 `/getInfo`、`/getRouters` 并进入 `/app` | 浏览器/Network |
| AC-04 | P0 | 已有 Token | 刷新页面 | Token 恢复，重新读取 `/getInfo`，不要求再次登录 | 浏览器 |
| AC-05 | P0 | Token 过期 | 调用受保护 API 返回 401 | 删除 Token、清空内存状态并跳转登录页 | 浏览器/Network |
| AC-06 | P0 | 已登录但无权限 | 调用 AI 权限接口 | 返回/显示 403，不把前端字段当权限依据 | 浏览器/后端 |
| AC-07 | P0 | 已登录 | 点击退出 | 调用 `/logout` 后 Token 清理；再次访问 `/app` 必须登录 | 浏览器/Network |
| AC-08 | P0 | 任意登录表单状态 | 构建、日志、Network 或存储检查 | 不出现密码、旧 Cookie、旧 auth 调用或第二个 Token | 静态/浏览器 |
