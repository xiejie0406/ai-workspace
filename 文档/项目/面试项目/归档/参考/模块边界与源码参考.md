## 1. 物理 module

| module | 当前职责 | 当前直接生产依赖 | 禁止 |
|---|---|---|---|
| `interview-domain` | 值对象、聚合、状态机、不变量和领域事件 | 无 | Spring、JPA、HTTP、SDK、adapter |
| `interview-application` | 用例契约、事务/Repository/Job/Provider ports、输入输出模型 | domain | adapter、Spring、数据库实体、厂商 DTO |
| `interview-adapters` | REST/SSE/WS 边界，安全失败映射，无外调默认 adapter；后续 persistence/provider | application、domain、Spring adapter 依赖 | 反向让 domain/application 依赖；业务规则 |
| `interview-boot` | main、Bean 装配、安全/配置、Flyway resources | adapters（传递 application/domain） | 业务状态和策略 |
| `interview-test-support` | 后续 builder/fake/container/Golden harness | domain、application | 生产 module 依赖、生产副作用 |

实际 POM 依赖方向：

```text
domain <- application <- adapters <- boot
domain <- test-support -> application
```

`frontend/` 和 `contracts/` 不属于 Maven reactor 的运行 module；前端只能通过版本化 API 访问服务端。

## 2. 第一波逻辑域

当前 domain/application 已开始实现：

- `platform`：ID、版本、事件、金额、用量、Job、Outbox、幂等与重试值对象。
- `identity`：User、Personal Tenant、Membership、Profile、Consent。
- `catalog`：Question、QuestionVersion、RubricVersion、Source、PublicationPolicy。
- `practice`：Attempt、Draft、不可变 AnswerVersion。
- `billing`：Entitlement、UsageReservation 及确定性预留状态。
- `interview`：Plan、Session、Turn、命令、状态和恢复稳定点。
- `agent`（application port）：Chat model 请求/结果/错误，不含厂商类型。

Evaluation、Learning、Voice、Governance、Operations 的完整生产模型尚未进入本参考的“已实现”列表；它们已有设计/契约候选，不得从文件树推断完成。

## 3. Boot/Adapter 当前行为

- `GET /api/v1/health` 返回服务名、release version 与 `UP`；不说明数据库、Provider 或业务链路就绪。
- 未匹配/解析/校验/安全错误使用统一 ErrorEnvelope 和 correlation ID。
- Security 默认仅允许公开 health，其他请求默认拒绝；没有临时开放业务 endpoint。
- ChatModel、ObjectStorage 和 Job 的默认 adapter 只返回/抛出“能力未配置”，不创建 HTTP client、线程、队列或 I/O。
- `V001__create_domain_schemas.sql` 只创建 12 个 schema namespace，没有业务表、role 或 grant。
