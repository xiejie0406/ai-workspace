# KnowFlow Phase 7 权限设计

> 阶段：Phase 7 权限、设置与工程化  
> 目标：让企业知识库具备角色权限和知识库访问控制。

## 1. 角色

| 角色 | 能力 |
| --- | --- |
| 超级管理员 | 全部权限 |
| 知识库管理员 | 管理授权知识库和文档 |
| 业务主管 | 查看日志、报告和质量任务 |
| 普通员工 | 提问和查看可访问知识库 |

## 2. 知识库权限

| 权限 | 含义 |
| --- | --- |
| `read` | 可提问、可查看回答 |
| `upload` | 可上传文档 |
| `manage` | 可编辑知识库和分段 |
| `audit` | 可查看日志和报告 |

## 3. 问答权限过滤

RAG 检索前必须过滤：

```text
用户可访问知识库
  -> 前端选择知识库
  -> 后端取交集
  -> 只检索允许范围
```

## 4. 验收

- 普通员工不能访问未授权知识库；
- 检索不会召回无权限文档；
- 管理员能配置知识库权限；
- 日志记录用户身份。
