# KnowFlow Phase 4 质量闭环设计

> 阶段：Phase 4 问答日志与质量闭环  
> 目标：把低质量回答变成可处理、可分派、可复测的运营任务。

## 1. 闭环流程

```text
AI 回答
  -> 用户反馈无用 / 系统判断未命中
  -> 问答日志标记风险
  -> 创建质量任务
  -> 管理员补文档 / 改分段 / 重建索引
  -> 复测同类问题
  -> 关闭任务
```

## 2. 触发条件

| 条件 | 风险 |
| --- | --- |
| 用户点无用 | 中 |
| 无引用回答 | 高 |
| 相关度低于阈值 | 中 |
| 高频未命中 | 高 |
| 引用了过期文档 | 高 |
| 文档入库失败 | 中 |

## 3. 质量任务类型

| 类型 | 说明 |
| --- | --- |
| `supplement_document` | 补充文档 |
| `review_answer` | 人工复核答案 |
| `rebuild_index` | 重建索引 |
| `adjust_chunk` | 调整分段 |
| `permission_check` | 检查权限范围 |

## 4. 任务状态

```text
todo -> assigned -> processing -> closed
todo -> closed
```

## 5. 复测设计

复测使用原问题重新执行 RAG，并比较：

- 是否有引用；
- 引用数量；
- 最高相关度；
- 回答是否命中原问题；
- 是否仍需要人工处理。

## 6. 验收

- 无用反馈能生成任务；
- 未命中问题能生成补文档建议；
- 任务状态可流转；
- 复测结果能回写日志；
- 工作台风险队列来自真实数据。
