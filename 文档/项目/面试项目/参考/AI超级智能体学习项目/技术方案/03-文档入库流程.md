# KnowFlow Phase 2 文档入库流程设计

> 阶段：Phase 2 文档入库与向量化  
> 目标：打通上传、解析、切片、向量化、失败重试。

## 1. 核心流程

```text
用户上传文件 / 提交 URL
  -> 创建文档记录
  -> 创建入库任务
  -> 解析文本
  -> 生成分段
  -> 写入向量库
  -> 抽样质检
  -> 文档 ready
```

## 2. 任务状态

| 状态 | 含义 |
| --- | --- |
| `queued` | 已创建任务，等待处理 |
| `parsing` | 正在提取文本 |
| `chunking` | 正在生成分段 |
| `indexing` | 正在写入向量库 |
| `checking` | 抽样质检 |
| `ready` | 入库完成 |
| `failed` | 入库失败 |

## 3. 文件来源

| 来源 | 处理方式 |
| --- | --- |
| PDF | Spring AI PDF Reader |
| Word | Apache POI 或后续补充 Reader |
| Markdown | Spring AI Markdown Reader |
| txt | 直接读取文本 |
| URL | Jsoup 抓取正文 |

## 4. 失败原因

| 原因 | 展示文案 | 处理建议 |
| --- | --- | --- |
| 文件过大 | 文件超过限制 | 重新上传较小文件 |
| 格式不支持 | 当前格式暂不支持解析 | 转为 PDF/Markdown |
| 文件加密 | 无法读取文档内容 | 上传未加密版本 |
| URL 需要登录 | 网页正文抓取失败 | 手动上传文档 |
| 向量写入失败 | 索引服务异常 | 重试入库任务 |

## 5. 前端状态

知识库详情页需要展示：

- 当前入库阶段；
- 每阶段进度；
- 失败原因；
- 重试入口；
- 分段预览入口。

## 6. 后端服务

```text
DocumentIngestionService
├── createUploadTask()
├── createUrlTask()
├── parseDocument()
├── splitChunks()
├── indexChunks()
├── runSampleCheck()
└── retryTask()
```

## 7. 验收

- 上传后能看到任务进度；
- 解析成功后生成 `kf_document_chunk`；
- 向量写入成功后文档状态为 `ready`；
- 失败时能看到错误原因并重试；
- 前端分段抽屉可以查看真实分段。
