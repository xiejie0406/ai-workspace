## 1. 原项目目前有什么

源码可定位到两条不同的能力线：一条是教程的 `BaseAgent`、`ReActAgent`、`ToolCallAgent`、`YuManus`，展示有步骤上限的 Agent 循环与 Spring AI Tool Calling；另一条是 KnowFlow 的知识库文档入库、PgVector 检索、问答引用、日志和质量任务。前端是 Vue 3，KnowFlow 页面中仍有部分 Mock 数据引用。项目还包含商品、报价、排产、仓库、财务、采购等 ERP 助手及桌面端实验，它们与本次面试主线无直接复用关系。本次只做源码与文档静态盘点，未启动原项目或验证这些业务链路。

原项目的后端 POM 是 Java 21、Spring Boot 3.4.4、Spring AI 1.0.0；当前若依聚合工程为 Java 17、Spring Boot 4.0.6。数据库、身份、权限、Agent 状态及 Provider 边界也不同，因此不能把原项目模块直接并入当前工程。
