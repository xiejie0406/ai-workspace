## 2. 问题、依据、目标与非目标

目标用户希望练习目标岗位的真实回答，获得有依据的下一问和可行动反馈。现有基础有题库、语音 Adapter、有限技术追问和评分框架，但真实实时性、标准接通与商业闭环仍无充分交付证据。

来源使用原研究的 FIND-01/03/04/07/10 和流程审阅 FLOW-GAP-01–13。供应商公开说法仅作产品参考；本轮没有新增市场事实或重新核验价格。最危险假设仍为：追问有增量价值、专家可对齐评分、用户据报告能改善；由 S2/S3 邀测验证，不靠更多 Agent 推定成立。

本 Feature 最终覆盖：有限范围资料、计划、手动语音确认、HR / 技术调度、计时 / 恢复、证据报告、历史与复练、本人反馈和数据控制。S1 仅内部技术验证“一题主问 + 条件追问”链路，不对外当作整场产品；S2/S3 完整后才具备邀测候选条件。支付与商业套餐为未来 S4 的独立规格，原 ¥39/3 场、¥99/10 场仅保留讨论，不作为本版销售承诺。

## 4. 业务规则（本轮细化，待审）

### BR-PILOT-01 配置与资料

仅 JAVA_BACKEND / MID / zh-CN / SIMULATION；轮次仅 HR、TECHNICAL 或 HR→TECHNICAL。首版采用可选手填项目资料和 JD，上传 / OCR 延后；服务端为资料生成不可变确认版本，区分本人确认自述与第三方核实。没有资料可以训练通用题，不因此扣分。

30 分钟为组合计划上限：8 分钟 HR、20 分钟技术、2 分钟收尾；单轮计划预留最后 2 分钟收尾。较短组合须经蓝图预留校验；8 分钟体验仅单轮。正文中题数是目标上限，不能许诺问满所有追问。

### BR-PILOT-02 开场和本题呈现

设备检测在本地完成，不保存检测录音、不扣训练额度。服务端开场前能力查询只读配置与配额，不谎称已探测供应商成功。正式开场仍可能失败，须有恢复或退出入口。

确认计划预留 1 次，15 分钟内未明确开始则释放；确认计划与会话唯一绑定，不因不同请求 key 重复建场。start 准备首题；页面显示“问题已就绪”，用户点击“开始作答”后服务端原子记录启用和计时，返回完整题面。开始确认之前不采集正式回答、不消费次数，用户接口不返回首题正文或可播放音频。后续题呈现后按题版本确认，不重复启用场次。

### BR-PILOT-03 手动结束、确认与纠错

点击“我说完了”仅停止录音，拿到稳定 final 后展示文本供用户确认；显式确认才生成正式答案。无语音、低置信或未知置信都不能自动提交。每次采集最多 180 秒；到上限仍待确认，允许在当前可用时间内改文字，不自动生成空答案。

同一题只能有一次正式确认；文本提交与转写确认共用规则。提交成功以服务端回答版本为准；请求超时先查 / 同 key 重试；相同 key 不同内容拒绝。

确认前可纠错；确认后原答案不可改写。S1 可在内部验证记录标注识别问题，S3 提供争议反馈和复核状态；未复核的争议证据不给确定等级。看过反馈后重新回答属于新练习，不覆盖首答。

### BR-PILOT-04 面试官决策

程序校验权限 / 状态 / 预算优先于模型建议。含义不清才澄清；证据缺口最多两次内容追问；全场额外语义澄清最多两次；语音重录独立限额。回答充分则换题；时间不足则记录缺口，不持续拷问。

轻量证据候选与下一问一次输出，来源引用校验后才能更新覆盖；最终评估重新回取原文。技术角色不接收 HR 主观标签或分数，只接收有来源的项目 / 职责线索。模拟中不展示评分锚点、答案、详细证据缺口；不启用提示工具。

### BR-PILOT-05 有效训练时钟

按服务端确认的题目呈现、正常朗读、思考、回答、用户文本修改 / 重听累计；系统 ASR / 模型 / TTS 首包等待、暂停、恢复和报告等待不计。时钟从首次开始确认启动，各等待原因受服务端验证，客户端不能任意报等待以延长训练。

全场与当前轮的剩余预算共同限制提问；收尾时段不再开新主问题。有效时间耗尽后冻结可采集内容；仅允许确认截止前已接收的稳定回答，60 秒内确认或明确排除，超时排除并说明。该窗口不允许增加答题内容。未来如需不同规则，发布新的策略版本。

网络断线通过服务端交互租约处理；发现失联后暂停计时，计时证据与恢复截止均从服务端读取。连接中断与供应商成本预算独立，不允许无限重连耗费。

### BR-PILOT-06 暂停、结束与恢复

pause 受理即改变版本，客户端立即停采 / 停播；在途模型不得落地。恢复窗从首次中断开始固定 24h，不因再次暂停延长；恢复不增加原场时间或次数。只有恢复到活动轮次才能重新采集。

complete 必须显式说明当前未确认内容是等待提交后结束还是排除；提交与结束按服务端版本顺序完成。输入冻结后不再接受任何新答案。取消未开始场次释放预留；放弃已开始场次不生成报告，不等于删除数据。

完成阶段失败恢复到完成意图，不能回到答题；评分失败只恢复评分。已确认答案应可回读；未确认音频断线不承诺恢复，不自动跨连接重放。

### BR-PILOT-07 分项与覆盖

逐维度匹配 0–4 行为等级；SCORED 必须有真实引文及适用锚点，INSUFFICIENT / CONFLICTING / DISPUTED 等非可评分情况不产生数值。首版统一不返回综合分或百分制总分；历史 80% 门槛不启用总分展示。

覆盖分母固定为已确认蓝图；分别展示已考察覆盖和可评分证据覆盖。跳过、未问到、识别争议、时间不足均有原因。相关原话存在也需检查其确实支持结论，不能只有子串相等验证。

### BR-PILOT-08 报告、复练与反馈

会话完成不表示报告完成。报告 READY 可包含诚实的证据不足；PARTIAL 表示有系统未完成的部分；FAILED 保留答案和恢复入口。复练建立新场次，用户开始前明确确认；同题复答与新题迁移分开，不输出不可比总分趋势。

反馈有编号、本人查询、处理状态、结果与替代报告版本；反馈不会直接改分。实际人工处理时效待配置运营能力，不预先承诺。没有允许保存的音频不显示可用回放；修订文本不得冒充音频逐字稿。

### BR-PILOT-09 数据与授权

本人可读 / 操作本会话，管理端默认不读回答原文；所有工具同样校验归属。仅同意的目的与 Provider 区域可处理数据，密钥不进入前端 / prompt / 日志。本人确认资料仍是不可信指令来源。首版只提供内部只读题库 / 标准 / 证据工具，无 SQL / Shell / 任意外网 / 支付。

邀测前需冻结隐私政策。候选沿用临时音频确认后 24h 清理、可选回放 30 天、回答 / 报告 180 天、备份 30 天；未确认音频从采集结束起 24h 清理，避免永久遗留。撤回先停止调用 / 发布，再清理派生数据；旧 Job 不得使已删数据复活。具体用户删除 / 撤回契约属于 S3，未完成不能开放真实用户邀测。

### BR-PILOT-10 邀测限额与交付边界

S1 仅内部固定样例 / fake 依赖验证，不售卖、不默认给所有用户入口。S3 邀测使用服务端分配的 INVITE_PILOT_V1 测试权益，额度 / 到期由受控运营配置，客户端不能领取或改数量。未开始释放、已开始结束结算、重试 / 重连 / 报告重跑不重复结算。

系统导致问答或核心证据反馈无法交付，按失败时间起 24h 有界恢复，最终失败返还一次测试权益；返还额度至少有 7 天使用窗口，保留台账。取消和答得不好不等于系统故障。真实现金 / 商业套餐政策留给 S4，本文不定义销售合同。

## 6. 质量、兼容与未决项

质量目标沿用[共用技术稿 §15](../../架构/面试项目完整设计.md#backend)，本版具体测量入口见 技术设计.md。首轮质量目标包括全场语音成功率≥95%、相关且不重复追问≥90%、专家分项差值≤1 的比例≥90%；需要分层样本，样本量与专家人员仍待确认，当前均未测。

兼容：v1 不改响应；0.2.0 是未发布 v2 的收敛候选，不将旧商业草案 0.1.0 当生产基线。发布 / 数据迁移 / 回滚另获授权。

未决项 owner 与门：产品评审本轮 BR 细则与交互（S1 前）；独立公共契约 / 隐私复核（S1 实现前）；实际模型版本、地区、配额、单场费用预算（真实 Provider 验证前）；完整岗位蓝图及评分专家样本（S2/S3 前）；用户隐私政策、数据管理与人工反馈职责（真实邀测前）。不以这些未决项阻止本轮文档准备，不据此宣称已经可上线。
