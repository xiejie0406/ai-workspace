## 2. 若依集成边界

面试项目使用若依账号、认证、角色、菜单和权限能力，但题库、面试、语音、评测、学习与计费仍是面试业务。身份、后端和双数据源边界统一见[完整设计的后端与数据边界](架构/面试项目完整设计.md#backend)；跨目录导航见[若依框架—面试集成入口](../../若依框架/README.md#面试集成入口)。

若依上游对照工程和其他项目不得从本项目文档推导自身的数据库或业务模块边界。
