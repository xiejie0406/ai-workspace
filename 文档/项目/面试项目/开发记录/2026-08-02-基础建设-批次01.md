## 1. 本波目标与边界

- 目标：在与 PaiCLI 完全独立的新目录中，建立五个后端 Maven module、稳定公共契约、最小 Boot/健康边界和 React 生产壳，并为后续逻辑域并行编码提供单向依赖基线。
- 范围：`pom.xml`、`backend/**` 的模块与第一波生产源码、`frontend/**`、`contracts/**`、无秘密配置模板和本开发记录。
- 非目标：不修复或覆盖两份截断的 Canonical 文档；不把候选产品行为标为 Approved；不接真实 Provider、音频、支付、对象存储、Redis、云或生产数据。
- 假设：工作名和 Java package 暂用 `AI Interview Coach` / `com.aiinterviewcoach`；在没有公开发布、持久化生产数据或外部 consumer 时可受控重命名。

## 5. 当前事实与限制

- 代码正在形成，只能称“局部实现中”。
- `application.yaml`、POM、TypeScript 与 Java 尚未经过编译或运行验证。
- 前端页面会调用尚未全部存在的 API；错误/空态用于真实失败反馈，不等于后端能力已实现。
- 两处 Canonical 截断、Gate A/C、原型评审和用户批准状态没有被本波改变。
- 真实 Provider、语音质量、数据地域、删除 SLA、支付渠道和生产配置仍必须在各自实现包前关闭。

## 6. 停止与恢复

- 发现 domain 依赖 Spring/JPA/HTTP、跨域 Repository、前端保存长期 token、日志写入敏感正文、migration owner 冲突或 PaiCLI 依赖时立即停止对应写入线。
- 需要改变公共 API、schema、产品状态或外部数据政策时退回阶段 3/5/6，由单一 owner 修订候选。
- 子 Agent 完成后由主协调 Agent执行只读集成审查；未获运行授权时结果继续为 `NotRun`。
