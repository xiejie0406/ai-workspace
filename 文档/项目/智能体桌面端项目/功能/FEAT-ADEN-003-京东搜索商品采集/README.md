## 1. 当前交付目标

**自己搜索 → 自己打开详情页 → 点击采集 → 管理已采集商品与图片 → 导出。**

当前拟交付以统一设计 1.2.3 为准（界面基线 1.2.0）：Chrome 按区提取与统一保存，桌面查看商品、版本、人工补充、图片整理及 Excel/ZIP 导出；登录直达统计工作台，取消手动新增商品、回收站和其他任务入口。自动搜索、翻页、打开详情、滚动和切规格仍不在首版范围。用户已基本认可界面并要求多智能体编码规划，随后明确“开始做”，三端已进入实际编码和定向验证，唯一安排仍见[多智能体实施规划](../../产品/统一设计文档.md#parallel-implementation)。本轮只隔离通道、接回原数据库；实际构建、原库缺表与安装同步状态维护于[实现与验证记录](实现与验证记录.md)，当前十八项业务与六项局部检查见[本轮报告](证据/2026-10-01-统一设计实现/verification-report.html)；旧验收结果保留原事实。
