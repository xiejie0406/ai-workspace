Aden 插件修复与逐项测试记录

2026-10-02 · 扩展文件 0.3.1 · 本机安装版 Aden Local Test · 原数据库 ry-vue

修复已同步；用户 Chrome 的实际侧栏复验尚未完成。

已确认的原因：缺少商品页面读取权限；新版京东标题与规格 DOM 和旧选择器不匹配。新增显式授权入口和模板适配。Chrome Host 注册已归一到当前安装目录；旧、新 Host 协议探针均通过，不将路径差异当作协议不兼容。

真实业务清单 23 项：0 通过、1 原失败未通过、22 受阻。修复后复验 23 项均受阻；原失败保留，不改写历史。技术检查 57 项插件、20 项 Host 通过，分别计数。

当前工具安全策略禁止接管 chrome://extensions/ 和 chrome-extension:// 内部页面；商品页后续调试又返回 Debugger unattached。没有通过其他通道绕过，也没有把模拟界面作为实际截图。

用户接受：待确认。重启后登录、配对、真实保存和原库数据核对未执行。

本机操作入口

  1. 在 Chrome 扩展管理页重新加载 Aden，版本应为 0.3.1。
  2. 仍为旧版时，加载 C:\Users\admin\AppData\Local\Programs\Aden Local Test\resources\collector\extension。
  3. 回到京东商品详情，从工具栏打开侧栏，点击“授权京东商品页”并允许访问，然后重新提取。
  4. 安装版重启后如回到登录页，由用户输入验证码登录，再连接并确认配对；未登录不能保存。
