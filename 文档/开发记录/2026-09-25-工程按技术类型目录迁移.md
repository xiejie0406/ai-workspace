## 已发生的迁移

迁移前，`platform-backend/` 为活跃 Java 工程，`ruoyi-backend/` 为若依上游基线。现已把活跃 Maven 工程放入 `ruoyi-backend/`，把原若依基线完整保存在 `ruoyi-backend/_reference/ruoyi-original/`。活跃工程的旧 `ruoyi-ui/` 放入 `frontend/_reference/ruoyi-ui/`，不属于 Maven 聚合模块。

| 原活跃路径 | 新路径 |

| `admin-web/` | `frontend/admin-web/` |
| `portal-web/` | `frontend/portal-web/` |
| `aden-desktop/` | `frontend/desktop/aden-desktop/` |
| `packages/` | `frontend/packages/` |
| `mobile/` | `miniapp/interview-mobile/` |

## 未提交内容与恢复

迁移开始前存在大量未提交的业务源码、配置、测试和文档改动。先移动若依上游基线，再复制占用中的活跃工程源码到目标目录；复制结果中源文件失败数为 0。用户确认可以停止本地占用进程后，已停止指向旧路径的 Java、Node、Python、Electron 进程，再把旧路径的原始内容转入 `.codex-tmp/legacy-paths-20260925/`。该备份在仓库内、被 `.gitignore` 排除，包含迁移前源码和当时的运行生成物；不要在核验前删除。原 `platform-backend/` 路径已清空并移除，其分段备份位于上述目录的 `platform-backend/`，旧若依基线则位于正式 `_reference/`。

若需要恢复迁移前的工作目录：先停止从新路径启动的进程；保存迁移后新增或修改的文件；按上表反向恢复各活跃工程，并将 `ruoyi-backend/_reference/ruoyi-original/` 还原为旧 `ruoyi-backend/`。其中 `.codex-tmp/legacy-paths-20260925/` 可用于逐文件比对和恢复迁移前的未提交内容。恢复时不得直接覆盖迁移后新增内容；先比较文件差异，再按明确的版本选择复制。

## 验证与限制

迁移未涉及真实数据库 schema、账号权限或外部发布。Java 模块仍由单个 `ruoyi-admin` 提供 HTTP 入口；APS Worker 的独立进程边界保持原样。迁移期间停止了 14 个命令行指向旧工程路径的本地 Java、Node、Python、Electron 进程；这些服务尚未按新路径重新启动，实际联机运行需单独验收。

迁移后对备份中的非生成源码逐项检查目标文件是否存在：后端 1,318 个、管理端 440 个、门户端 28 个、桌面端 72 个、小程序 377 个、选品 Python 86 个，缺失均为 0。此检查证明路径覆盖，不替代文件内容差异审查。执行 `mvn -f ruoyi-backend/pom.xml -pl ruoyi-admin -am -DskipTests compile --no-transfer-progress` 与同范围 `package`，18 个 Maven 模块均成功；`ruoyi-admin` 可执行包已在新目录生成，包内包含面试、选品、Aden 和 APS API 模块。`mvn -f ruoyi-backend/pom.xml -pl :aps-worker -am -DskipTests package --no-transfer-progress` 成功生成独立 Worker 可执行包。构建时跳过了测试；另有定向 Java 测试 11 个、桌面端测试 55 个、Python 测试 71 个通过。

`frontend/admin-web/` 类型检查与生产构建、`frontend/portal-web/` 构建、`miniapp/interview-mobile/` H5 构建、`frontend/desktop/aden-desktop/` 构建均成功。`node scripts/aps/check-imp01-structure.cjs` 为 32/32 通过，`node scripts/aps/verify-migration.cjs` 为 10/10 通过，Git Bash `bash -n scripts/aps/verify-linux-runtime.sh` 语法检查通过。`git diff --check` 通过。`scripts/check-docs.ps1` 仍失败，仅剩迁移前已存在的 Aden 证据文件 `verification-report.html` 非中文命名；此文件及入链保持原样。本轮验证不证明数据库和外部服务联机。
